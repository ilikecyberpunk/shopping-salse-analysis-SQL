# 쇼핑몰 주문·매출 분석 SQL

## 1. 프로젝트 소개

MySQL을 활용하여 온라인 쇼핑몰의 고객, 상품, 주문 데이터를 관리하고 매출을 분석하는 SQL 학습 프로젝트입니다.

SQL의 JOIN, GROUP BY, HAVING, 서브쿼리, PK/FK, 인덱스, 트랜잭션을 실습하는 것을 목표로 합니다.

## 2. 사용 기술

- Database: MySQL
- Tool: MySQL Workbench, VS Code
- Version Control: Git, GitHub

## 3. 데이터베이스 구조

| 테이블 | 설명 |
|---|---|
| customers | 고객 정보 |
| products | 상품 정보 |
| orders | 주문 정보 |
| order_items | 주문별 상품 정보 |

## 4. 주요 기능

- 전체 매출 조회
- 고객별 총구매금액 조회
- 상품별 판매량 분석
- 매출 상위 상품 조회
- 주문 이력이 없는 고객 조회
- 날짜별 매출 분석
- 트랜잭션을 활용한 주문 처리

## 5. 프로젝트 파일

- `01_schema.sql`: 테이블 생성 및 제약조건
- `02_data.sql`: 테스트 데이터
- `03_analysis.sql`: 매출 분석 SQL

## 6. 실행 방법

1. MySQL 서버에 접속합니다.
2. `01_schema.sql`을 실행하여 테이블을 생성합니다.
3. `02_data.sql`을 실행하여 테스트 데이터를 삽입합니다.
4. `03_analysis.sql`을 실행하여 분석 결과를 확인합니다.

## 7. 학습한 내용

- PK와 FK를 이용한 테이블 관계 설계
- JOIN을 이용한 여러 테이블 조회
- GROUP BY와 집계 함수 활용
- 서브쿼리를 이용한 조건 검색
- 트랜잭션을 이용한 데이터 변경 관리

## 8. 개선할 점

- 대량 데이터에서 인덱스 성능 비교
- 복잡한 매출 분석 쿼리 최적화
- Java JDBC를 활용한 데이터베이스 연동
